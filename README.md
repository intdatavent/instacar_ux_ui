# INSTACAR SERVER

## Structure

This repo contains the InstaCar server that enables the communication between client and backend.

1) server.py is the server
2) run_backend.sh is the file where the all backend logic will run
3) images/ folder contains bkg images used for blending
4) uploads/ is the folder containing all the input-output data
5) templates/ contains the console .html file

## RUN

To run the server:
```
python server.py
```

**N.B.** You will need all the other backend repos (in the correct structure) to correctly process the input images.
